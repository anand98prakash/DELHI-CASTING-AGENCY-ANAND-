## Severity Scale Summary

- **P0 — Critical**: Security flaw, server crash, or data corruption. (Immediate blocker)
- **P1 — High**: Core workflow broken (e.g. unable to apply or post casting call).
- **P2 — Medium**: Minor feature malfunction with workaround available.
- **P3 — Low**: Cosmetic layout, text alignment, or minor typo issue.

---

## Status Definitions

- **`OPEN`**: Issue reported by client; awaiting developer triage.
- **`IN_PROGRESS`**: Issue reproduced and patch being implemented.
- **`RESOLVED`**: Patch verified and re-tested in UAT environment.
- **`OUT_OF_SCOPE`**: Item categorized as future feature request or out-of-scope requirement.
